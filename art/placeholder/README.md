# Pip

Original artwork for Capri Companion: a teal-and-brass lantern maintenance robot.
The silhouette, palette, and design were authored from basic shapes with no reference artwork.
Licensed under this project's PolyForm Noncommercial terms.

Rebuild the committed transparent 240×420 PNG with `node scripts/create-placeholder.mjs`.
It uses the mochi-v1 neck, shoulders, hip, and knee positions. The round head sits near
the MANE pivot without representing hair. No face anchor, portraits, cut-ins, or intro
frames are declared; those effects stay disabled.
